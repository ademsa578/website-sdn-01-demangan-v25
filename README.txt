EDITOR WEBSITE DARI LUAR (PERSIAPAN)
- Folder admin/ berisi kerangka Decap CMS dan config.yml.
- Editor belum aktif untuk publik sampai website diunggah ke hosting, repository GitHub yang benar dimasukkan ke admin/config.yml, dan autentikasi OAuth dikonfigurasi dengan aman.
- Jangan membagikan password/token GitHub. Gunakan akun sekolah dan batasi akses hanya untuk pengelola yang dipercaya.
- Konten pada file content/pengaturan.yml adalah data awal editor; agar perubahan semua bagian situs tampil otomatis, tampilan website perlu dihubungkan ke data CMS pada tahap pemasangan. File HTML versi ini masih memuat sebagian besar isi secara langsung, jadi jangan menganggap CMS sudah terhubung penuh.
- Dokumentasi CMS: https://decapcms.org/docs/
